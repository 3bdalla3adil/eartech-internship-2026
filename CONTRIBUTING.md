# Contributing

## Branch flow
`feature/<your-name>-<task>` -> `team-x/sprint-N` -> `team-x/develop` -> `develop` -> `main`

- Team A (CourseHub) uses `team-a/*` branches; Team B (HealthPulse) uses `team-b/*` branches.
- Never push directly to `main`, `develop`, or `team-x/develop`. Open a pull request.
- Every pull request needs Scrum Master approval before merging.
- Never commit secrets or `.env` files.

## Commit messages
Use short, clear messages, e.g. `feat: add student registration form`.
